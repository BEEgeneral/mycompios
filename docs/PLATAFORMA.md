# MyCompi — Plataforma

## Overview

MyCompi es una plataforma SaaS B2B que proporciona **equipos de agentes IA especializados** para PYMEs. Cada agente tiene memoria, conoce la empresa y ejecuta tareas concretas de forma autónoma.

## Modelo de Negocio

```
Empresa registra → Trial 3 días → Plan Pro (€49/mes) → Upsells
                                           ↓
                    ┌─────────────────────────┴──────────────────────────┐
                    │                                                  │
               €19/hora                                           €49/mes
          Autonomous Mode                                      Pro Plan
       (ejecución continua)                                 (tasks + credits)
```

## Sistema de Créditos

| Plan | Precio | Credits/mes | Notes |
|------|--------|-------------|-------|
| **Trial** | Gratis (3 días) | 5 | Todos los agentes activos |
| **Pro** | €49/mes | 5 | Tasks + reports |
| **Autonomous** | €19/hora | - | Ejecución continua |

## Agentes

| Agente | Rol | Frecuencia | Funciones |
|--------|-----|-----------|-----------|
| **Pelayo** | Executive | Cada 60 min | Decisiones, approve credits, strategy |
| **Paco** | Operations | Cada 30 min | Enviar reminders, process payments |

| **Enzo** | Marketing | Cada 60 min | Content, social |

## Revenue por Feature

- **€49/mes Pro** — Plan base con credits
